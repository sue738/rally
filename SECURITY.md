# Security

## Reporting a vulnerability

Please report it privately. Open the **Security** tab of this repository and choose
**Report a vulnerability**, or go straight to
<https://github.com/sue738/rally/security/advisories/new>. Please do not open a public
issue for it.

Include the Rally version, the macOS version and the steps to reproduce.

## Supported versions

Fixes go into the latest release only.
